# AI Studio Build 用プロンプト（teizaiha-lab）

## 第1部：最初に貼るプロンプト

```
「端で決まる定在波ラボ」という日本語のWebアプリを作ってください。

## 何を作るか
高校「物理基礎／物理」の波の単元で、生徒が1人1台で使うシミュレーション教材です。
ひもを伝わる波が壁で反射して戻ってくる様子を動かして見せ、「固定端では端が節、自由端では端が腹になる」ことを、予想 → 再生 → 確かめるの順で自分の目で確かめます。
問いや記述は先生が口頭やワークシートで出すので、アプリは「見て確かめる道具」に徹してください。文章の入力欄やレポート機能は作りません。
端末は Chromebook・iPad・スマホが混在します。

授業で投げかける問い（スタート画面に表示する）：
「同じ振幅・波長の波が左右から進んできて重なると、波が進まずその場で揺れる『定在波（定常波）』ができます。端がガッチリ固定された『固定端』と、端が自由に動ける『自由端』では、端はそれぞれ定在波の『節（まったく振動しない点）』と『腹（最も大きく振動する点）』のどちらになるでしょうか？」

## 全体の構成
スタート画面と、7つのステップを順に進む。上部に進み具合（①〜⑦）を表示し、終わったステップにはいつでも戻れる。
ただし ③〜⑦ は、② で固定端・自由端の両方の予想を選ぶまで開けない（ロックのアイコンを表示）。

①〜⑥ のシミュレーション画面は共通の型にする：
- 上：波の表示エリア（canvas）。横長。ひも・波・壁・印を描く
- 中：操作バー
  - 再生／一時停止、コマ送り（1/20 周期ずつ進む）、最初から
  - 速さ：ふつう（×1）・スロー（×0.25）・とてもスロー（×0.1）
- 下：表示の切り替え（チェックボックスかトグル）と、そのステップの短い指示文（2〜3行）
  - 入射波（青）・反射波（赤）・合成波（黒の太線）・まぼろしの波（灰の点線）・残像・節と腹の印・λ の目盛り
  - ステップに関係ないものは切り替えを出さない（例：① では反射波・まぼろしの波を出さない）

## 物理モデル（この式と定数どおりに計算してください）
座標は画面上の「マス」で表す。表示する範囲は x = 0〜12 マス、y = −2.5〜+2.5。
- 振幅 A = 1、波の速さ v = 2 マス/秒（速さ ×1 のとき）
- 波長 λ：初期値 3.2 マス（スライダーで 2.0〜5.0）
- k = 2π/λ、振動数 f = v/λ、ω = 2πf、周期 T = 1/f
- 壁の位置 L：初期値 8.0 マス（ドラッグで 4.0〜10.0）
- 時刻 t は「再生」を押した瞬間を 0 とし、速さの倍率をかけて進める

### ① 重ねてみる（壁なし）
- 右向きの波：y1 = A sin(ωt − kx)（青）
- 左向きの波：y2 = A sin(ωt + kx)（赤）
- 合成波：y = y1 + y2 = 2A cos(kx) sin(ωt)（黒）
- x = 0〜12 の全体に、最初からずっと存在するものとして描く

### ②〜⑥ 壁あり（ひもは x = 0 の波源から x = L の壁まで）
- 入射波（青）：y_i(x, t) = A sin(ωt − kx)。ただし波の先頭より先（x > v·t）は 0
- 反射波（赤）：
  - 固定端：y_r(x, t) = −A sin(ωt − k(2L − x))
  - 自由端：y_r(x, t) = +A sin(ωt − k(2L − x))
  - どちらも、壁で折り返した道のり 2L − x を進むまでは届かないので、2L − x > v·t のところは 0
  - つまり、入射波の先頭が壁に届いた瞬間（t = L/v）に、壁から反射波が出始める。それより前に反射波が見えてはいけない
- 合成波（黒）：y = y_i + y_r（0 ≤ x ≤ L）
- 節と腹の位置（0 ≤ x ≤ L の範囲だけ）：
  - 固定端：節 x = L − n·λ/2、腹 x = L − λ/4 − n·λ/2（n = 0, 1, 2, …）
  - 自由端：腹 x = L − n·λ/2、節 x = L − λ/4 − n·λ/2
- まぼろしの波（灰の点線、x = L〜12 に描く）：y_g(x, t) = A sin(ωt − kx)。入射波が壁がないものとしてそのまま進んだ波。先頭の条件（x > v·t は 0）も入射波と同じ
- 壁をドラッグしている間・λ を変えている間は、立ち上がりを省いて「十分時間がたった状態」（先頭の条件なし）で描き直す

### 計算の確かめ（コードで自動チェックし、?debug=1 のときだけ画面の隅に結果を表示）
- 固定端：t > L/v のとき、x = L の合成波の変位がつねに 0（誤差 1e-9 以下）
- 自由端：t > L/v のとき、x = L の合成波の振幅（直近1周期の最大値）が 2A
- 定在波ができた範囲で、節の位置の変位がつねに 0、腹の位置の振幅が 2A
- 黒線の値が、青線と赤線の値の和と一致している

物理の計算（y_i、y_r、合成波、節と腹の位置）は、描画から切り離した純粋な関数として1つのファイル（physics.ts）にまとめてください。定数（A、v、λ の範囲、L の範囲、表示範囲）も1つのファイルにまとめ、あとで調整しやすくしてください。

## 表示のきまり
- 残像：直近1周期分の合成波の線を、古いものほど薄くして重ねる。これで揺れの包絡線が浮かび、節と腹が見える
- 節と腹の印：節は「●節」、腹は「▲腹」。定在波ができている範囲（入射波と反射波の両方が届いている範囲）だけに出す。③④では、予想の答え合わせが出るまで印を出さない
- λ の目盛り：ひもの下に、壁から λ/2 ごとの目盛りを描く
- 端の点：x = L の点を大きめの丸で強調し、表示エリアの右上に「端の揺れ幅：0.00 A」のように、直近1周期の最大変位を数値で出す
- 固定端の絵：ひもが壁にくぎで留めてある
- 自由端の絵：ひもの先に軽いリングがあり、壁の代わりの縦の棒をなめらかに上下にすべる
- 固定端・自由端の切り替えはボタン2つ（絵つき）

## ステップごとの内容

### スタート
- 授業の問い（上の文）と、①〜⑦ の流れを一覧で表示。「はじめる」ボタン

### ① 重ねてみる
- 壁なし。青い波と赤い波が逆向きに進み、黒い合成波が「進まずにその場で揺れる」ことを見る
- 「残像」と「節と腹の印」を入れると、節と腹が浮かぶ
- 指示文：「黒い線は、右へも左へも進んでいない。まったく動かない点と、大きく揺れる点を見つけよう」

### ② 予想する
- 右端に壁が現れた絵を、固定端・自由端の2つ並べて静止画で見せる
- それぞれに「端は 節？ 腹？」の2択ボタン。選んだボタンを強調する
- 両方選ぶと「再生して確かめよう」ボタンが押せるようになり、③ へ進む
- 答えは保存しない（画面を閉じたら消える）

### ③ 固定端で再生
- 固定端。再生すると、左の波源から入射波が壁へ進み、壁に届いた瞬間から反射波が戻り始める。反射波が届いた範囲から定在波ができていく
- 最初は入射波・反射波・合成波の3本を表示
- t ≥ L/v + 2T になったら、答え合わせのカードを出す：
  - 「あなたの予想：節 → 予想どおり！」または「予想とちがった」
  - 1行の説明：「固定端では、反射波が上下反転して戻ってくる。端では入射波と反射波がいつも打ち消し合うので、端は動かない＝節になる」
- 答え合わせのあとで、節と腹の印を出せるようにする

### ④ 自由端で再生
- 自由端。③と同じ流れ
- 答え合わせの1行：「自由端では、反射波がそのままの向きで戻ってくる。端では入射波と反射波がいつも強め合うので、端は大きく揺れる（揺れ幅 2A）＝腹になる」

### ⑤ まぼろしの波
- 固定端・自由端を切り替えられる。壁の向こう（x > L）に、まぼろしの波を灰の点線で描く
- 「折り返してみる」ボタン：波を一時停止し、まぼろしの波が壁を軸にくるっと折り返すアニメーション（約1.5秒）を見せる
  - 進み具合 s = 0 → 1 で、点 (x, y) を (L + (x − L)·cos(πs), y·c(s)) に動かす
  - c(s) は、固定端では cos(πs)（上下も反転する）、自由端では 1（上下はそのまま）
  - 折り返し終わった点線が、赤い反射波にぴったり重なることを見せる（重なったら点線を一瞬光らせる）
- 指示文：「固定端は、壁の向こうの波を上下ひっくり返して折り返すと反射波。自由端は、そのまま折り返すと反射波」

### ⑥ 壁を動かしてみる
- 壁（またはリングの棒）を左右にドラッグできる（x = 4.0〜10.0）。λ のスライダーも出す
- どこに壁を置いても、固定端なら端は節、自由端なら端は腹のまま、節と腹の並びが壁ごと付いてくることを見る
- λ の目盛りで、節どうし（腹どうし）の間隔が λ/2 であることを確かめる
- 指示文：「壁を動かしても、端はいつも同じ。節と腹の並びは、端から決まっている」

### ⑦ くらべる
- 固定端（上段）と自由端（下段）を同じ λ・同じ L で並べて、同時に動かす
- 各段の横に「反射波：上下反転する／そのまま」「端：節／腹」を表で示す
- 授業の問いをもう一度表示し、「答え：固定端は節、自由端は腹」を、タップで開くカードにしておく

## 見た目
- 高校生向け。白い背景に落ち着いた配色。入射波＝青、反射波＝赤、合成波＝黒、まぼろしの波＝灰の点線を全画面で統一する
- 日本語UI。用語ははじめて出るときに「節（まったく振動しない点）」「腹（最も大きく振動する点）」のように言いかえを添える
- 幅 360px のスマホ縦画面でも崩れないこと。波の表示エリアは横長のまま画面の上に置き、縦が小さくなりすぎないようにする（最低でも高さ 200px 程度）。操作と切り替えはその下にまとめる
- タッチ操作が主役。壁のドラッグ中にページがスクロールしないようにする（canvas に touch-action: none）。ボタンは指で押しやすい大きさにする
- アニメーションは requestAnimationFrame で動かし、古い Chromebook でもカクつかないようにする。線は端から端まで1ピクセル刻み程度でなめらかに描く

## データ
- 保存は一切しない。localStorage も使わない。予想の選択も画面を閉じれば消える
- ログインなし。入力欄なし
- サーバーとの通信なし

## 技術の条件
- サーバーなしで動く静的なWebアプリ（GitHub Pages で公開できること）
- Gemini API など外部AIの呼び出しは入れない
- APIキーをコードに書かない
- 外部ライブラリは最小限。波は canvas で自前で描く
```
