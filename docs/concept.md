# 端で決まる定在波ラボ（teizaiha-lab）

## ひとことで
高校物理の生徒が1人1台で、波が壁で反射して戻ってくる様子を見ながら、「固定端では端が節、自由端では端が腹になる」ことを、予想 → 再生 → 確かめるの順で自分の目で確かめるアプリ。

## 利用者と場面
- 高校「物理基礎／物理」波の単元（波の反射・定在波）。授業中に1人1台で使う
- 授業で投げかける問い：「同じ振幅・波長の波が左右から進んできて重なると、波が進まずその場で揺れる定在波ができる。端がガッチリ固定された固定端と、端が自由に動ける自由端では、端はそれぞれ節と腹のどちらになるか？」
- 問いや説明の記述は先生が口頭やワークシートで出す。アプリは「見て確かめる道具」に徹する
- 端末は Chromebook・iPad・スマホが混在（想定）。縦長のスマホ画面でも操作できること

## 学びの目的
- 定在波は、逆向きに進む同じ波の重ね合わせで、波形が進まずに「節（動かない点）」と「腹（最も大きく揺れる点）」が並ぶことがわかる
- 固定端では反射波が上下反転して戻る（位相が π ずれる）ため、端は入射波と反射波が打ち消し合って**節**になると説明できる
- 自由端では反射波がそのままの向きで戻るため、端は強め合って**腹**になると説明できる
- 節と節（腹と腹）の間隔は λ/2 で、並びは端の条件から決まることがわかる（誤解：節や腹の位置はたまたまそうなる／壁の位置と関係ない）
- 反射波の作図法（壁の向こうへ延ばした波を、固定端は上下反転して、自由端はそのまま折り返す）を、動く図と結びつけられる

## 体験の流れ（利用者目線）
1. **重ねてみる**：左から右へ進む青い波と、右から左へ進む赤い波を出す。重ねた黒い合成波が「進まずにその場で揺れる」ことを見る。「残像」を入れると、揺れの包絡線が浮かび、節（●）と腹（▲）の印が出る
2. **予想する**：画面の右端に壁が現れる。「固定端（ひもを壁にくぎ付け）」「自由端（ひもの先のリングが棒をすべる）」のそれぞれで、端の点が「節」か「腹」かをタップで選ぶ。**選ぶまで再生ボタンは押せない**。答えは保存しない
3. **固定端で再生**：左から入射波が壁に向かって進み、壁に届くと反射波が戻り始める。反射波が届いた範囲から定在波ができていく。端の点（印つき）がまったく動かないことを見る。再生後に「予想どおり／ちがった」と1行の説明が出る
4. **自由端で再生**：同じ流れで、端のリングが大きく上下に揺れる（振幅 2A）ことを見る。「予想どおり／ちがった」が出る
5. **まぼろしの波を出す**：壁の向こうに、入射波がそのまま進んだと考えた「まぼろしの波」を点線で描く。固定端では上下反転して、自由端ではそのまま、壁で折り返すと反射波にぴったり重なるアニメーションを見る
6. **壁を動かしてみる**：壁をドラッグして左右にずらす。どこに置いても、固定端なら端は節、自由端なら端は腹のまま、節と腹の並びが壁ごと付いてくる。波長スライダーも動かし、節どうしの間隔が λ/2 であることを目盛りで確かめる
7. **くらべる**：固定端と自由端を上下2段に並べた比較画面。反射波の向き（反転する／しない）と、端が節か腹かを1枚で見比べる

## 画面一覧
- スタート：問いの文と、7ステップの流れ
- シミュレーション画面（①〜⑥で共通の型）
  - 上：ひもと波の表示エリア（入射波＝青、反射波＝赤、合成波＝黒の太線、まぼろしの波＝点線、残像＝薄い帯、節●・腹▲の印、λ の目盛り）
  - 中：操作バー（再生／一時停止／コマ送り、速さ：ふつう・スロー・とてもスロー、最初から）
  - 下：表示の切り替え（入射波・反射波・合成波・まぼろしの波・残像・節と腹の印を個別に ON/OFF）と、ステップごとの短い指示文
  - スマホ縦画面では、波の表示エリアを横長のまま上に置き、操作と切り替えを下にまとめる
- 予想パネル：固定端・自由端それぞれに「節」「腹」の2択ボタン。再生後に正誤と1行の説明
- 比較画面：固定端と自由端の2段表示

## 物理モデル（指示書にそのまま書く）
- ひもは x = 0（左の波源）から x = L（壁）まで。振幅 A、波長 λ、振動数 f、波の速さ v = fλ、k = 2π/λ、ω = 2πf
- 入射波：y_i(x, t) = A sin(ωt − kx)。ただし波の先頭より先（x > vt）は 0
- 反射波（固定端）：y_r(x, t) = −A sin(ωt − k(2L − x))。反射波は壁で折り返した道のり 2L − x を進んだ分だけ遅れて届くので、2L − x > vt のところは 0
- 反射波（自由端）：y_r(x, t) = +A sin(ωt − k(2L − x))。届く範囲の条件は固定端と同じ
- 合成波：y = y_i + y_r
- まぼろしの波（x > L に描く）：y_g(x, t) = A sin(ωt − kx)。これを x = L で折り返す（x → 2L − x）と反射波、さらに固定端では上下反転すると反射波になる
- 節と腹の位置：固定端は節が x = L − n·λ/2、腹が x = L − λ/4 − n·λ/2。自由端はその逆（n = 0, 1, 2, …、0 ≤ x ≤ L の範囲だけ）
- ステップ①（重ねてみる）は壁なしで、y = A sin(ωt − kx) + A sin(ωt + kx)
- 壁をドラッグしている間・波長を変えている間は、立ち上がりを省いて「十分時間がたった状態」の式で描き直す

## 計算の確認用（取り込み後にスクリプトでも確かめる）
- 固定端：反射波が届いたあと、x = L での合成波の変位がつねに 0
- 自由端：反射波が届いたあと、x = L での合成波の振幅が 2A
- 定在波ができた範囲で、節の位置の変位がつねに 0、腹の位置の振幅が 2A
- 表示している黒線が、青線と赤線の和と一致している

## データと公開範囲（保存の有無・ログインの有無・個人情報）
- 保存：なし。予想の選択も画面を閉じれば消える（localStorage も使わない）
- ログイン：なし。名前の入力欄もない
- 個人情報：入力欄そのものがないので扱わない
- 一般公開（URLを配るだけで使える）。Firebase は使わない

## 試作で確かめたいこと（AI Studio Build で見たい点）
- 入射波の先頭が壁に届いた**その瞬間から**反射波が戻り始めるか（早すぎたり、壁に届く前に反射波が見えたりしないか）
- 固定端で端の点が本当に1ピクセルも動かないか、自由端で端のリングが 2A まで揺れるか
- 予想を選ぶまで再生できないか。予想の前に結果（節・腹の印や比較画面）が見えてしまわないか
- まぼろしの波を折り返すアニメーションが、反射波と重なって見えるか
- 壁のドラッグと波長スライダーが、スマホ・iPad・Chromebook のタッチパッドで動かしやすいか
- 「とてもスロー」と「コマ送り」で、節が止まっていることを目で追えるか
- 縦長のスマホ画面で、波の表示が小さくなりすぎないか

## やらないこと
- 予想・記述・結果の保存やレポート出力
- 弦の固有振動（基本振動・倍振動）、開管・閉管の気柱、共鳴の扱い（次のアプリの候補）
- パルス1つの反射だけを見せるモード
- 減衰や、端が「半分固定」のような中間の条件
- 教師による集計・クラス全体への共有

## 反映した教訓
- 物理モデルを数式と定数のまま書いた（シミュレーションの計算がずれないように）
- 「壁に届いた瞬間に反射波が戻り始める」というタイミングの条件を、試作で確かめたいことに入れた
- 「走らせる前に結果が見える」穴を防ぐため、予想を選ぶまで再生できない流れにした
- 表示の正しさを数値で確かめる「計算の確認用」を置いた（表示の誤りは教材として誤解を生む）
- 専門用語に絵を添えた（固定端＝くぎ付けのひも、自由端＝棒をすべるリング）
